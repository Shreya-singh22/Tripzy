# Tripzy - Travel Portal Website

A modern, fully client-side travel booking simulation built with HTML5, CSS3, and JavaScript.

## About

Tripzy is a single-page application that simulates a complete travel booking experience - from user registration to trip confirmation. Built entirely on the front-end with no backend or database, it demonstrates advanced web development concepts including form validation, dynamic price calculation, and responsive design.

## Features
- **User Registration** with real-time validation (phone, PIN, email)
- **Travel Blog** showcasing 5 destinations with image carousels
- **Trip Planner** with interactive price calculator
- **Booking Confirmation** with confetti animation
- **Responsive Design** with hamburger menu for mobile
- **LocalStorage** for data persistence

## Quick Start

1. Clone the repository
2. Open `index-merged.html` in any modern browser
3. Start planning your dream trip!

Alternatively, use Live Server in VS Code for the best experience.

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with CSS variables
- **JavaScript (ES6+)** - Vanilla JS, no frameworks
- **Feather Icons** - Icon library via CDN

## Project Structure


## Key Highlights

-  **No Backend Required** - Fully static, works offline
-  **19 Trip Options** - Destinations, travel, food, activities
-  **Real-time Validation** - Instant feedback on form inputs
-  **Auto-play Carousels** - 15 destination images with lazy loading
-  **Mobile-First Design** - Responsive from 360px to 1920px+
